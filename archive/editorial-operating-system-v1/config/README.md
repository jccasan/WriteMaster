# Editorial Operating System — Complete Suite

A modular fiction-editing and beta-reader system with independent reviewer identities, shared project memory, issue tracking, revision verification, subject-matter routing, and publishing-stage evaluation.

## What is included

- Volume 1: editorial constitution, novel bible, issue memory, output standards, and managing editor.
- Volume 2: developmental, line, copy, continuity, and revision-verification skills.
- Volume 3: federal, intelligence, legal, medical, military, forensic, cyber, and reviewer-routing skills.
- Volume 4: commercial thriller, pacing, character, dialogue, emotional impact, mainstream accessibility, and series-ending readers.
- Volume 5: literary-agent, acquisitions, market-positioning, and submission-package readers.
- A tailored *Oracle Veil* project pack with scene prompts, character readers, panel configuration, and a starter issue ledger.

## Skill count

25 installable skill folders are included under `skills/`.

## Start here

1. Read `RUNBOOK.md`.
2. Complete `shared/assets/PROJECT_BRIEF_TEMPLATE.md` and `shared/assets/NOVEL_BIBLE_TEMPLATE.md`.
3. For *Oracle Veil*, begin with `project-packs/oracle-veil/PROJECT_BRIEF.md` and `PANEL_CONFIG.md`.
4. Run reviewers independently.
5. Use `editorial-director` and `MASTER_ORCHESTRATOR_PROMPT.md` to synthesize.
6. Record decisions in the issue ledger.
7. Use `revision-verifier` on the next draft.

## Important limits

These skills are structured editorial roles, not substitutes for verified current research or licensed professional advice. Subject-matter reviewers must state uncertainty and should trigger fresh research when precision matters. Publishing-market and comparable-title claims must be researched at the time of use.

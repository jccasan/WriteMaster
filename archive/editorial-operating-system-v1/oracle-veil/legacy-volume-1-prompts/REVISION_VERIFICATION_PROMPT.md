# Revision Verification Prompt

You are verifying a revised manuscript against a prior editorial issue ledger.

For each issue:

1. Find the original problem.
2. Inspect the revised text.
3. Determine whether the reader-facing problem is fixed.
4. Check whether the revision created new problems.
5. Assign one status: FIXED, PARTIALLY-FIXED, NOT-FIXED, DISPLACED, WORSENED, OBSOLETE, or DECLINED-AUTHOR-CHOICE.
6. Give a concise evidence-based note.

Do not praise a change merely because text was added. Judge effect.

Output:

| Issue ID | Status | Evidence | New risk | Recommended next action |

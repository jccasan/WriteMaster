# Panel Selection Matrix

| Need | Primary skill | Optional second opinion |
|---|---|---|
| Story feels wrong but cause is unclear | developmental-editor | commercial-thriller-reader |
| Chapters drag | pacing-suspense-reader | developmental-editor |
| Character choice feels unearned | character-arc-reader | emotional-impact-reader |
| Dialogue feels flat | dialogue-voice-reader | line-editor |
| Facts or dates conflict | continuity-logic-auditor | relevant SME |
| Federal operation feels questionable | federal-procedure-reviewer | legal-realism-reviewer |
| Covert program or classified material | intelligence-tradecraft-reviewer | legal-realism-reviewer |
| Injury or recovery drives plot | medical-realism-reviewer | continuity-logic-auditor |
| Climax works but ending feels crowded | series-ending-reader | developmental-editor |
| Prose needs polish | line-editor | novel-copy-editor |
| Preparing to query | literary-agent-reader | submission-package-auditor |
| Positioning is unclear | market-positioning-reader | acquisitions-editor-reader |
| Checking a new draft | revision-verifier | original reviewer only if needed |
